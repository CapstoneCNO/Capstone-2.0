# Documentation Repository

This repository contains all documentation associated with the **WSI Plaque Analysis Platform**, including setup guides, architecture overviews, handover documents, technical specifications, and operational procedures.

It serves as the central knowledge base for developers, maintainers, collaborators, and research partners who work with or support the system.

This documentation repository is maintained separately because the main application codebase is private and stored in:

**https://github.com/CapstoneCNO/Capstone-2.0_SOURCE_CODE**

Keeping documentation in its own public or semi-public repository ensures that contributors and external partners can access all relevant information without exposing the proprietary source code.
